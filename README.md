# CommunityLevelSave（CommunityLevelSave）

> 解除每日挑战的自动存档限制：战斗中每 3 秒自动保存全量战场进度（滑动存档），退出后当天重新进入同一关时自动恢复——阳光、已种植物、僵尸波次进度、场上僵尸等与游戏原生存档同等还原度。死亡/通关自动清档防刷；存档按关卡日期自动隔离。

## 安装

把 `dist/CommunityLevelSave.pmod` 放进游戏的 Mods 目录，或在 Mod 管理里导入。
